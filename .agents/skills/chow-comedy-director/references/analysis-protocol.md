# 分析规程与字段词典

## 时间与边界

源 PTS 是解码帧的呈现时间，可能不从零开始。clip 秒数从第一视频帧开始。
SMPTE timecode 是素材元数据的标签，不保证与 PTS 同原点；记录标签、帧率、有无分号和来源，未经确认不换算。
所有区间用 [start,end)，帧索引从 0 开始。代理保留所有帧且不改变播放速率，时间戳可能因 Matroska 精度误差约 1ms；frame-map.csv 保留原始精度。
不处理旋转烘焙：代理保留编码方向，方向信息见源 ffprobe；人工观看时留意旋转标签。

## 逐镜头分析

- framing_camera：景别、机位、角度、运动、视线/轴线，分别记录观察与功能假设。
- performance：目光、呼吸、面部张力、动作幅度、台词速度、停顿、反应延迟；不要把角色心理当成直接观察。
- blocking：人物相对位置、距离、进出画、前后景、权力变化、观众可见与角色不可见的信息差。
- gag_mechanism：预期建立方式、偏移点、身份/地位逆转、字面化、重复升级、因果错位、反应不对称；允许多机制或无笑点。
- sound：对白、拟音、环境声、音乐、静默、声画同步/错位、声音先入与延后；无音轨与无声音不能混为一谈。
- editing_rhythm：镜头时长、动作接点、反应镜头、笑点前停顿、兑现后留白、观众理解所需时间。
- observation / hypothesis / confidence / counterexample：事实与解释分栏；confidence 为 low/medium/high 并写理由；主动寻找相反解释。
- method_ids：用分号连接方法 ID；所有结论需可回查原片，不以关键帧代表连续表演。

## 喜剧节拍 CSV

beat_id 为稳定 ID；shot_ids 用分号关联多个镜头；source_start/end_pts_seconds 用原始时间轴。
phase 可为 setup / expectation / deviation / payoff / reaction / aftermath / other。
记录观众当下知道什么、期待什么、何时被纠正，区分台词信息与镜头信息。
记录节拍内动作、表演、声音、切点的相互依赖，timing_seconds 只记实测时长。
替代假设示例：效果可能来自演员反应而非停顿长度；用固定其他变量的原创实验验证。

## 方法提炼与原创检验

先给每条观察注明证据边界和复核状态，再归纳适用条件、操作、预期效应与失败条件。
至少跨不同情境验证后才讨论可迁移性；不能把某位演员的个人特质当成普适规律。
原创迁移描述只包含抽象导演约束和新的情境变量，不提供原片对白复写或逐动作重演。
先检查人物目标是否自洽、预期是否清晰、偏移是否可读，再安排节奏实验。
缺少观众数据时，方法 status 保持 hypothesis；confirmed 必须有复核证据和独立实验结果。
